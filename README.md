파이썬 기반의 CLI(Command Line Interface) 퀴즈 프로그램으로, 증기기관의 역사와 원리에 대해 학습하고 관리할 수 있는 도구입니다.

## 1. 프로젝트 개요
이 프로젝트는 객체 지향 프로그래밍(OOP)과 JSON 데이터 처리를 학습하기 위해 제작되었습니다. 사용자는 퀴즈를 풀고, 새로운 문제를 추가하거나 기존 문제를 관리할 수 있으며, 모든 데이터는 로컬 파일에 영구적으로 저장됩니다.

## 2. 퀴즈 주제와 선정 이유
*   **주제:** 증기기관 (Steam Engine)
*   **선정 이유:** 
    *   산업 혁명의 핵심 기술로서 역사적, 공학적 가치가 높음.
    *   제임스 와트, 뉴커먼 등 명확한 역사적 사실과 작동 원리(압력, 응축 등)가 퀴즈 콘텐츠로 적합함.
    *   기술의 발전 과정을 단계별로 학습하기에 최적의 주제임.

## 3. 실행 방법
1.  Python 3.x 버전이 설치되어 있어야 합니다.
2.  터미널(또는 CMD)에서 프로젝트 폴더로 이동합니다.
3.  아래 명령어를 입력하여 게임을 실행합니다.

    ```bash
    python quiz_game.py
    ```

## 4. 기능 목록
*   **퀴즈 풀기:** 저장된 문제 중 무작위로 출제되며, 결과는 백분율(%)점수로 계산됩니다.
*   **퀴즈 추가:** 새로운 문제와 정답을 입력받아 저장합니다. (빈 칸 입력 방지 검증 포함)
*   **퀴즈 목록 보기:** 현재 저장된 모든 퀴즈의 질문과 정답을 확인합니다.
*   **최고 점수 확인:** 역대 최고 기록 점수를 확인합니다.
*   **퀴즈 삭제:** 인덱스 번호를 통해 특정 퀴즈를 삭제할 수 있습니다.
*   **데이터 영속성:** 모든 변경 사항은 `state.json`에 즉시 반영되어 프로그램 재시작 후에도 유지됩니다.
*   **예외 처리:** `Ctrl+C`(KeyboardInterrupt)나 잘못된 입력에도 프로그램이 비정상 종료되지 않도록 설계되었습니다.

## 5. 파일 구조

